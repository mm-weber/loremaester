# Specification: OCR routing — per-page hybrid + region-targeted figure OCR

**Track ID:** ocr-hybrid-routing_20260607
**Type:** Feature
**Priority:** Medium
**Created:** 2026-06-07
**Status:** Complete

## Summary
Replace `ingest_books.py`'s binary OCR routing (image-only → OCR; everything else → R2R native) with a
per-page **hybrid** for image-only AND mixed PDFs: use each page's embedded text layer where present,
OCR pages that lack one, and OCR embedded **image regions** (figures) to capture text baked into them —
appended to the text layer with no de-duplication. Pure text-native PDFs keep fast R2R-native parsing.

## Context
`process_pdf` routes via `is_image_pdf` (<10% text → OCR), so easyocr ran only on the fully-image
Vol III; mixed PDFs (e.g. "Planes of Law", 206/320 text pages) go to R2R native and their ~114
image-only pages get **no client-side OCR** (lost in Light Mode). The GPU should OCR wherever a page —
or a figure on a page — actually lacks a text layer, not re-OCR perfect text.

## Acceptance Criteria (EARS)
- [x] THE ingest router SHALL send pure text-native PDFs to R2R-native ingestion (unchanged).
- [x] WHEN a PDF is image-only OR mixed THE ingest router SHALL extract it via the per-page hybrid and ingest the result as text (temp `.txt`, preserving title + default collection).
- [x] WHEN a page has a usable embedded text layer THE hybrid SHALL use that text and SHALL NOT OCR the page body.
- [x] WHEN a page has no usable text layer THE hybrid SHALL OCR the whole page.
- [x] WHERE a page has an embedded image region that is not a full-page scan duplicating an existing text layer THE hybrid SHALL OCR that region and append its text to the page's text.
- [x] WHERE the requested engine is easyocr AND no usable CUDA GPU is present THE OCR SHALL fall back to tesseract (with a printed notice).
- [x] IF a document yields no text on any page THEN THE hybrid SHALL raise a document-identifying error (no empty ingest).
- [x] THE hybrid SHALL depend only on permissively-licensed components (pypdfium2, pdfplumber, pytesseract, easyocr/torch).

## Dependencies
Builds on `remove-kreuzberg_20260606` (ocr_extract) and `idempotent-ingest_20260607`. Adds `pdfplumber`
to `ocr_extract.py`'s deps (already used elsewhere in the repo). Edits `scripts/ocr_extract.py`,
`scripts/ingest_books.py`, their tests, and the OCR docs.

## Out of Scope
- Figure OCR on **pure text-native** books (they stay on R2R native — known limitation).
- Whole-page-OCR + fuzzy/page-level **de-duplication** (rejected in favor of region-targeted OCR).
- A `--force` / re-ingest flag; the `ocr_preprocess.py` helper.

## Technical Notes
Region OCR maps pdfplumber image bboxes (top-origin points) to rendered pixels via `RENDER_SCALE`,
crops the pypdfium2-rendered page, and OCRs the crop — disjoint from the text layer, so no dedup.
Guard: skip a ~full-page image when the page already has a text layer (scanned-with-text → trust the
layer). Reuse `render_pages` / `ocr_image` / `make_reader` / `OcrExtraction`; reuse the 3-tier
classifier from `detect_pdf_type.py`. Coordinate alignment (points×scale → pixel crop, top-left origin)
is the one fiddly bit — validate by cropping a known mixed page.
