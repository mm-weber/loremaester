# Specification: Idempotent ingest — skip already-ingested PDFs

**Track ID:** idempotent-ingest_20260607
**Type:** Bug
**Priority:** Medium
**Created:** 2026-06-07
**Status:** Draft

## Summary
`scripts/ingest_books.py` should treat R2R's "document already exists" response as a **SKIP**
(idempotent re-run), not a **FAILURE** — and report succeeded / skipped / failed separately.

## Context
R2R rejects re-ingesting an existing document with `R2RException: Document <id> already exists…`.
The current catch-all reports that as `FAILED`, so re-running the ingest on an already-populated
corpus prints a misleading "0 succeeded, N failed" even though every book is present. Re-running is
the first thing a new user does, so this is a real UX trap. (Surfaced during the v0.1 OCR debugging,
where every "failure" was actually an already-ingested document.)

## Acceptance Criteria (EARS)
- [ ] WHEN ingesting a PDF that R2R reports already exists THE ingest script SHALL classify it as SKIPPED, not FAILED.
- [ ] THE ingest script SHALL print a per-file `SKIPPED` line naming the file when it skips an existing document.
- [ ] THE final summary SHALL report separate counts for succeeded, skipped, and failed.
- [ ] IF an ingest error is NOT an "already exists" error THEN THE script SHALL classify it as FAILED, printing its type + message (full traceback when `INGEST_DEBUG` is set).
- [ ] WHEN every PDF in a run is already ingested THE script SHALL report 0 failed.
- [ ] THE skip-on-exists behavior SHALL apply to both ingest paths (image-only via OCR and text-native via R2R native).

## Dependencies
None. Edits `scripts/ingest_books.py` + `scripts/test_ingest_books.py`. Builds on track
`remove-kreuzberg_20260606`.

## Out of Scope
- A pre-ingest existence check that skips OCR *before* re-OCRing an already-ingested image PDF
  (efficiency optimization) — **Future Consideration**.
- A `--force` / `--reingest` flag (delete + recreate) — **Future Consideration**.

## Technical Notes
Detection: match `"already exists"` in the R2R exception message (avoids importing R2R's internal
exception class, which is fragile). Extract the per-PDF routing + error handling out of `main()` into
a testable `process_pdf(client, pdf) -> "succeeded" | "skipped" | "failed"`.
